# TypeNova

Original typing-learning platform, built with Next.js, React, TypeScript, and browser-local functionality first.

## Phase 1
- Original responsive visual identity
- Home page and navigation
- Responsive typing test
- Gross/net WPM and accuracy calculation
- 15s–5m modes
- Live error highlighting and completion/retry flow

## Run
npm install
npm run typecheck
npm run lint
npm run build
npm run dev

No API keys or paid services are required for the current phase.
