# TypeNova

Original typing-learning platform, built with Next.js, React, TypeScript, and browser-local functionality first.

## Current product
- Original responsive visual identity
- Home dashboard and navigation
- Unlimited typing in Learn, Practice, Test, Games, and Focus
- Gross/net WPM, accuracy, real accuracy, consistency, errors, and active-time metrics
- Rotating passages and multiple typing modes
- Custom drills using letters and numbers
- Character-by-character result review
- Learn curriculum with virtual keyboard and finger guidance
- Progress analytics with WPM, accuracy, consistency, practice time, and key performance

## Run
npm install
npm run typecheck
npm run lint
npm run build
npm run dev

No API keys or paid services are required for the current phase.
